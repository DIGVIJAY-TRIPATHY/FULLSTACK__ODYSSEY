# OptiMedia AI
# THE MAIN PROJECT IS IN THE REPO : https://github.com/DIGVIJAY-TRIPATHY/OptiMedia_AI

**AI-powered media transformation and optimization SaaS.**

OptiMedia AI is a cloud-based platform that allows users to upload images and videos, transform them into different sizes and formats, and optimize media using **Cloudinary**.

## Features

* 🖼️ Resize and transform images for different frame sizes
* ✂️ Smart image cropping and aspect-ratio transformation
* 🎥 Optimize and compress videos
* ☁️ Cloudinary-powered media processing
* 📊 Manage uploaded and processed media
* 🔐 User authentication
* 📱 Responsive dashboard
* ⚡ Fast cloud-based processing

## Tech Stack

* **Next.js** — Full-stack React framework
* **Cloudinary** — Image & video processing
* **Prisma** — Database ORM
* **NeonDB** — PostgreSQL database
* **DaisyUI** — UI components
* **Tailwind CSS** — Styling

## How It Works

```text
Upload Media
     ↓
Select Transformation
     ↓
Cloudinary Processing
     ↓
Optimized Media
     ↓
Download / Use
```

### Image

Users can upload an image and generate different versions based on the required frame size or aspect ratio.

Example:

```text
Original Image
      ↓
 ┌────┼────┬────┐
 ↓    ↓    ↓    ↓
1:1  4:3  16:9  9:16
```

### Video

Users can upload large videos and generate optimized versions with reduced file size and suitable quality for web delivery.
